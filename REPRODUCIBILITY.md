# Reproducibility package

This repository contains the code, inputs, processed outputs, and figure-generation files used for the manuscript *A 99-Line Homogenization Code for Lattice-skin Plate Structures*.

## Archival record

- Archived source release: [`v1.0.0`](https://github.com/TopJournals/ThinWalledHomogenization/releases/tag/v1.0.0)
- Release commit: the commit identified by the annotated `v1.0.0` Git tag
- Raw-data deposit: the DOI-backed record linked from the `v1.0.0` release metadata

Results in the manuscript should cite the tagged release or its linked DOI record rather than the moving `main` branch.

## Tested environment

The revised benchmarks were generated with the following fixed configuration:

| Component | Version or configuration |
|---|---|
| Operating system | Windows 10, build 10.0.26200 |
| Python | 3.11.10 |
| NumPy | 1.26.4 |
| SciPy | 1.14.1 |
| CuPy | 13.3.0 (`cupy-cuda12x`) |
| CUDA runtime reported by CuPy | 12.6 |
| CUDA driver API reported by CuPy | 13.2 |
| GPU | NVIDIA GeForce RTX 3060 |
| CPU | AMD Ryzen 9 7950X 16-Core Processor |
| CPU thread settings | `OMP_NUM_THREADS=1`, `OPENBLAS_NUM_THREADS=1`, `MKL_NUM_THREADS=1` |
| Detailed finite-element solver | Abaqus/Standard 2022, build 2021_09_16-01.57.30 176069 |

Install the fixed Python environment with:

```bash
python -m pip install -r requirements.txt
```

The Abaqus ODB extractor requires the Python interpreter bundled with Abaqus and the `odbAccess` module. `Paper/render_all_vtus.py` requires ParaView's `pvpython`; these two vendor-provided environments are not pip packages.

## Repository structure

| Path | Role |
|---|---|
| `core/` | Mechanical, multimaterial, and thermal homogenization solvers |
| `utils/` | TPMS and BCC voxel-geometry generators |
| `examples/` | Base-case, multiple-layer, multimaterial, and thermal examples |
| `benchmarks/` | Mesh, truncation-sensitivity, and repeated CPU/GPU timing scripts and outputs |
| `abaqus/` | Detailed-model input generation, ODB extraction, and coupling-plot scripts |
| `Paper/` | Figure notebooks, Abaqus input decks, processed output tables, and plot-ready data |
| `scripts/check_appendix_sync.py` | Verifies that the manuscript appendix reproduces the archived 99-line core solver exactly |

## Manuscript artifact manifest

| Manuscript item | Input or cached data | Analysis or generation script | Archived output |
|---|---|---|---|
| Homogeneous and asymmetric two-layer analytical verification | Material, layer, and resolution definitions in `benchmarks/verify_analytical_abd.py` | Same file | `benchmarks/r2_m2/analytical_abd_benchmarks.json` |
| Base TPMS and BCC examples | Parameters in `examples/ex01_tpms_simulation.py` and `examples/ex01_2_lattice_simulation.py` | Same files | Printed ABD matrices |
| Thickness-size and LVS-H comparison | `Paper/truncation_sensitivity_sweep.csv`, `Paper/truncation_sensitivity_lvs_references.csv` | `benchmarks/sweep_truncation_sensitivity.py` | `Paper/truncation_sensitivity_lvs_summary.csv` |
| Mesh-resolution study | Resolution settings in `benchmarks/benchmark_plate_solver.py` | `benchmarks/benchmark_plate_solver.py` | `benchmarks/benchmark_plate_solver_N20_125_step5.csv` and `.json` |
| Repeated CPU/GPU timing | Protocol in `benchmarks/benchmark_end_to_end.py` | `benchmarks/benchmark_end_to_end.py` | `benchmarks/r2_m5/benchmark_end_to_end_runs.csv`, `benchmark_end_to_end_summary.csv`, and `benchmark_end_to_end_metadata.json` |
| Diamond extension-twist validation | `Paper/abaqus_diamond_tension_twist_hex_r64/diamond_tension_twist_hex_r64.inp` | `abaqus/extract_diamond_coupling_from_odb.py` and `abaqus/plot_diamond_coupling_from_csv.py` | `diamond_odb_coupling_metrics.csv` and `diamond_odb_coupling_metrics_xmax_u3_profile.csv` in the same folder |
| Original manuscript plots | Cached data within `Paper/Fig1.ipynb`, `Paper/Fig31.ipynb`, and `Paper/Fig32.ipynb` | Same notebooks | Generated raster/vector figures are excluded from Git because they can be regenerated |
| VTU rendering | VTU files generated by the multiple-cell example | `Paper/render_all_vtus.py` | Rendered images are excluded from Git |

The Abaqus `.odb` databases and other transient solver files are excluded from Git because the largest database is approximately 1.65 GB. The DOI-backed data deposit should contain the raw ODB used for the Diamond validation. The GitHub release retains the corresponding input deck, extraction scripts, metadata, and processed CSV outputs so that every number reported in the manuscript remains traceable without downloading the raw database.

## Reproduction commands

Run the core examples from the repository root:

```bash
python examples/ex01_tpms_simulation.py
python examples/ex01_2_lattice_simulation.py
python examples/ex02_multiple_cells.py
```

Regenerate the two analytical ABD verification cases:

```bash
python benchmarks/verify_analytical_abd.py
```

Regenerate the LVS-H-referenced sensitivity outputs from cached LPS-H data:

```bash
python benchmarks/sweep_truncation_sensitivity.py --plot-only
```

Regenerate the repeated timing dataset:

```bash
python benchmarks/benchmark_end_to_end.py
```

Regenerate the Diamond input deck and process an Abaqus ODB:

```bash
python abaqus/generate_diamond_tension_twist_inp.py --help
abaqus python abaqus/extract_diamond_coupling_from_odb.py --help
python abaqus/plot_diamond_coupling_from_csv.py --help
```

## Appendix consistency check

Appendix A of the manuscript must reproduce `core/plate_homogenizer.py` verbatim, including comments and blank lines. From the repository root, run:

```bash
python scripts/check_appendix_sync.py --manuscript ../R2603_paper/11_Manuscript.tex
```

The release must not be tagged unless this command reports an exact 99-line match.
